# Flipside Backend

The server application for Flipside.

It will provide authenticated APIs for memories, orders, payments, printing, and fulfillment.

## Technology

- Next.js
- TypeScript
- Clerk
- Neon Postgres
- Drizzle ORM
- Zod
- Stripe

Database, authentication, and payment integrations will be introduced separately.
